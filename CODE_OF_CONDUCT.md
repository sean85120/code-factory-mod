# Code of conduct

This project is for building a useful tool together. To keep it a place people
want to contribute to:

- **Be respectful.** Disagree with ideas, not with people. No harassment,
  insults, discrimination, or personal attacks, in any form or venue connected to
  the project.
- **Be constructive.** Say what is wrong and, where you can, what would fix it.
  Assume good faith, and ask before assuming bad.
- **Be welcoming.** Newcomers ask basic questions. Answer them kindly or point to
  the docs.
- **Respect privacy.** Do not share other people's personal information, and do
  not paste secrets, tokens or private repository contents into issues or pull
  requests.

## Enforcement

Maintainers may edit or remove comments, close issues and pull requests, and
block people who break these rules. To report a problem, open the repository's
**Security** tab and choose **Report a vulnerability** (it is a private channel
to the maintainers), or contact a maintainer through their GitHub profile.
Reports are handled privately.

This code of conduct applies in the project's issues, pull requests, discussions
and any space where someone represents the project.
